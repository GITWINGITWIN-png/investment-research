# Loop prompt สำหรับ label ข่าวอัตโนมัติ

คัดลอกทั้งบล็อกข้างล่างไปวางต่อท้าย `/loop ` ใน Claude Code

---

```
label ข่าวจากคิวจนหมด แล้วหยุด ทำตามนี้เท่านั้น ห้ามด้นสด:

1. รัน `uv run finbg label prepare`
   - ถ้าขึ้นว่า "ไม่มีข่าวที่รอ label" → หยุด loop ทันที งานเสร็จแล้ว
   - ถ้าสำเร็จ มันจะพิมพ์ path ของไฟล์คำสั่งออกมา

2. อ่านไฟล์คำสั่งนั้น แล้วทำตามที่เขียนไว้ในไฟล์อย่างเคร่งครัด
   - ใส่ model ID จริงของคุณ ถ้าไม่ใช่ claude-opus-5 ให้หยุดแล้วรายงาน
   - ตัดสินจากข้อมูล ณ วันที่ข่าวออกเท่านั้น

3. เขียนไฟล์คำตอบตามชื่อที่ไฟล์คำสั่งระบุ

4. รัน `uv run finbg label ingest`
   - ถ้าปฏิเสธบางรายการ ให้รายงานเหตุผลไว้ แล้วไปรอบถัดไป

5. วนกลับข้อ 1

หยุด loop ทันทีเมื่อเข้าเงื่อนไขใดเงื่อนไขหนึ่ง:
- prepare บอกว่าไม่มีข่าวเหลือ
- ทำครบ 8 รอบแล้ว (กันวนไม่รู้จบ)
- ingest เก็บได้ 0 รายการ 2 รอบติดกัน (แปลว่ามีอะไรผิด)
- เจอ error ที่ไม่เข้าใจ

ข้อห้าม:
- ห้ามใช้เครื่องมืออื่นนอกจาก Bash(uv run finbg ...), Read, Write บน data/queue
- ห้ามแก้โค้ดใน finbg/ ห้ามแตะ data/labels/ หรือ data/raw/ โดยตรง
- ถ้าติดปัญหาที่ต้องแก้โค้ด → หยุดแล้วรายงาน อย่าพยายามแก้เอง

จบแล้วรายงานสั้น ๆ: ทำไปกี่รอบ เก็บได้กี่ label ปฏิเสธกี่รายการ เจอปัญหาอะไรไหม
```

## ทำไมออกแบบแบบนี้

**ไม่ต้องใช้ cron สำหรับ prepare** — loop เรียกเองในข้อ 1 ทำให้ไม่มีสถานะค้างระหว่างระบบสองตัว

**หยุดเองเสมอ** — backlog มีจำกัด (~67 ข่าว/วันหลังกรอง) จึงจบใน 2-3 รอบ ไม่ใช่วนทั้งคืน
เพดาน 8 รอบเป็นกันชนกรณีที่ ingest ปฏิเสธทุกรายการแล้วข่าวชุดเดิมวนกลับมา

**ข้อห้ามชัดเจน** — ถ้ามีอะไรผิดตอนตี 2 เราต้องการให้มันหยุด ไม่ใช่ให้มันพยายามซ่อมเอง
(permission ที่ตั้งไว้บังคับข้อนี้อยู่แล้ว แต่เขียนย้ำเพื่อไม่ให้เสียเวลาลองแล้วติด)

## ควรรันตอนไหน

| เวลา | ผลลัพธ์ |
|---|---|
| **ก่อนนอน (22:00-24:00)** ✅ | label ข่าวที่เก็บตอน 06:00 วันเดียวกัน → `days_after_publish = 0` |
| 02:00 ❌ | ข่าวล่าสุดมาจาก 06:00 **เมื่อวาน** → เก่าไป 20 ชม. |
| หลัง 06:30 | ได้ข่าวสดสุด แต่คุณอาจตื่นแล้ว |

`daily.sh` รัน 06:00 เพราะตลาดสหรัฐฯ ปิด 04:00 เวลาไทย — **อย่าเลื่อนให้เร็วกว่านี้** ราคาจะไม่ครบ

## ตรวจผลตอนเช้า

```bash
uv run finbg label stats      # ดู provenance + คำเตือน drift
uv run finbg label backfill --dry-run   # เช็คว่ามี days_after_publish ที่หายไปไหม
```
